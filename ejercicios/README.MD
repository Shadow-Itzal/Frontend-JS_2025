# 🍷 La Cantina de Frases

## 📌 Descripción del Proyecto
**La Cantina de Frases** es un sitio web básico desarrollado como parte de un curso de **Front-End**.  
El proyecto tiene como finalidad aprender y practicar la **estructura semántica en HTML**, utilizando las etiquetas principales:

- `<header>` → Encabezado de la página.  
- `<main>` → Contenido principal.  
- `<footer>` → Pie de página.  

La página se encuentra preparada para futuras mejoras con **CSS** y **JavaScript**, lo que permitirá enriquecer la experiencia visual e interactiva del usuario.  

---

## 🎯 Objetivos de Aprendizaje
- Comprender y aplicar el **HTML semántico**.  
- Construir la **estructura básica de una página web**.  
- Preparar la base para integrar estilos con **CSS**.  
- Dejar el proyecto listo para agregar interactividad con **JavaScript**.

## 📩 Formulario con Formspree
Para el formulario de contacto se utilizó [Formspree](https://formspree.io), un servicio que permite recibir mensajes de un formulario HTML sin necesidad de programar un backend propio.

### 🔧 Pasos de Configuración
1. Crear una cuenta en Formspree.  
2. Registrar el correo electrónico donde se recibirán los mensajes.  
3. Copiar la URL especial que brinda Formspree y pegarla en el atributo `action` del formulario.  
4. Definir el método como `POST` para que los datos viajen correctamente.  

### ⭐ ¿Por qué es útil?
- Permite que un formulario HTML simple envíe mensajes reales a un correo electrónico.  
- No requiere configurar PHP, Node.js ni bases de datos.  
- Es rápido, gratuito en su plan básico y perfecto para proyectos pequeños o educativos.
